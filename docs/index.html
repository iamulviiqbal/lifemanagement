İnteqrasiya

Bu kanalın tasklarını xarici sistemdən avtomatik oxu: qeydləri orada aparırsınız, izləməni burada. Tasklar oxunma rejimindədir — klik etdikdə xarici sistemdə açılır.

trello.com/power-ups/admin → New → Power-Up yaradın (adı sərbəst, workspace-inizi seçin) → soldan API key bölməsi → "Generate a new API key". Key-in yanındakı Token linki ilə icazə verib tokeni götürün. Sonra "Lövhələri yüklə" basıb lövhəni seçin.

Token: notion.so/my-integrations → New integration. Bazanı inteqrasiyaya bağlamağı unutmayın (baza səhifəsində ⋯ → Connections). Notion brauzerdən birbaşa qoşulmağa icazə vermir — README-dəki pulsuz Cloudflare Worker proxy quraşdırmasını edin (5 dəqiqə).

Cihazlar arası sinxronizasiya

Tasklarınız GitHub hesabınızdakı gizli Gist-də saxlanılır — pulsuz və yalnız sizə görünür. Qoşulduqdan sonra bütün cihazlarda eyni məlumatları görəcəksiniz.

  1. GitHub-da: Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token (classic) düyməsinə basın
  3. Ad yazın (məs. "lifemanagement"), müddət seçin (No expiration olar)
  4. İcazələrdən yalnız gist xanasını işarələyin → Generate token
  5. Yaranan ghp_... kodunu kopyalayıb aşağıya yapışdırın
